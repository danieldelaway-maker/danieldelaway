Privacy policy

Last updated 12 October 2026.

SLS3 Dashboard

SLS3 Dashboard is a private reporting tool built by Daniel Delaway for SLS3. It is used only by authorised SLS3 team members. It connects, with the account owner's permission, to the SLS3 Google Ads account and reads advertising performance figures (spend, clicks, conversions and revenue) so they can be shown in an internal report.

What we access and store

The app has read-only access to Google Ads reporting data for SLS3's own account. It does not read, change or create ads or campaigns, and does not access any personal data of members of the public. Access credentials are stored securely and are used only to fetch these reports.

Sharing

Data is not sold, shared with third parties or used for advertising. It is shown only to authorised SLS3 team members.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
